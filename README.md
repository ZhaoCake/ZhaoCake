### 🚀 What I'm Building

- 🔥 **Booting from scratch**: Skipping the Buildroot magic, hand-rolling cross-compilers, U-Boot, Kernel, and rootfs to truly understand the Linux boot chain.
- 🐛 **Taming multi-core debug chains**: Wiring up JTAG daisy-chains and configuring OpenOCD to peek into the silicon.
- ⚡ **RISC-V with Chisel**: Crafting 5-stage RV32I pipelines, dealing with hazards, and verifying against reference models (DiffTest).
